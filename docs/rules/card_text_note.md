# 一条效果的完整表述：
单个关键词
效果种类（或代表效果种类的关键词） + 冒号“：”表示后面是效果内容 + （效果条件，如果有） + （“时”“后”等表示效果条件结束的词） + （效果代价，如果有，种类表达在不满足时不能发动效果） + （“才能发动”等表示效果代价的词） + 具体执行效果

# 
每条效果用句号。（或英文.）隔开

文本中的\是用于生成卡图时的辅助符号，具体含义：
\火\水\气\地\光\暗\无：分别表示7种元素，\无表示奥术
\攻：攻击力
\血：生命值
\威：威力值

技能牌的效果适用负面状态作为单个关键词时表示攻击命中成功对目标造成该负面状态

为了简洁，强制/可选 不放在效果种类里面，但是会尽量使用“必须”“可以”两种词汇，如果没有就默认为强制效果。效果种类需要包含主动效果、条件效果、光环效果的分类，我用“诱发”这个新关键词来表达条件效果，这样更明确

大部分效果的作用目标默认为己方，攻击类作用目标默认为敌方（如果还有不明确的我会补充详细）
例如：主动回合技：丢弃1张手牌才能发动，获得2点所丢弃卡牌属性种类的元素，这个效果对于每个奥术以外的属性一局只能使用1次
等同于：主动回合技：你丢弃1张你的手牌才能发动，你获得2点所丢弃卡牌属性种类的元素，此卡的这个效果对于每个奥术以外的属性一局只能使用1次

另外再解释一下效果代价，刚才例子中丢弃手牌即为代价，不满足代价时不能发动这个效果

目前还有一些效果默认为主动效果，如献祭，默认为主动发动，把该卡献祭（即送去弃牌堆）才能发动

小tip:
可选诱发绝技或回合技在没有选择触发时不会消耗绝技次数
反制效果不存在强制触发，默认为可选触发
