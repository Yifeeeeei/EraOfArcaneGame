# 规则文档入口

本目录用于整理《奥术纪元 / Era of Arcane》的正式规则、术语和卡牌文本规范。

建议阅读顺序：

1. `core-rules.md`：当前已经确认的核心规则，面向玩家和开发者阅读。
2. `glossary.md`：正式术语表，用于统一规则和卡牌文本中的词汇。
3. `card-text-style-guide.md`：卡牌文本表述规范，用于后续重写卡牌描述。
4. `rule_manual.md`：规则作者原稿，保留设计来源和更自由的说明。
5. `rule-manual-feedback.md`、`rule-manual-feedback-v2.md`：阶段性反馈清单，记录规则迭代中的问题和回答。

和代码实现有关的对照文档在：

- `../project/rules-implementation-audit.md`

规则定稿时，以 `core-rules.md` 和 `glossary.md` 为准；若它们与反馈文档或旧原稿冲突，优先更新正式文档。
