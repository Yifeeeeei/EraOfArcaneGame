# 卡牌文本表述规范

本文档用于统一《奥术纪元 / Era of Arcane》的卡牌文字写法。目标是让每张卡的表述既适合玩家阅读，也能被开发者稳定实现。

卡牌文本不是运行时解析来源。运行时效果必须由结构化字段和 Go 行为实现；本文档负责规定玩家可读文本怎样写。

## 1. 基本原则

- 每个效果必须明确分类：主动、条件或光环。
- 每个触发或执行效果必须能判断是强制还是可选；牌面未写“可以”时默认强制，写“可以”时对应触发或执行部分视为可选。
- 每句话只表达一个明确效果或限制。
- 明确对象、时机、费用、数量、持续时间和失败处理。
- 同一种机制始终使用同一种句式。
- 不通过描述文本推断机制；机制应映射到结构化字段、关键词或行为代码。
- 避免“相关”“若可以”“根据情况”“等”等模糊表述。

## 2. 效果分类

每个卡牌效果先判断属于以下三类之一。

卡牌数据中使用结构化字段记录分类：

- `effect_categories`：填写效果类型，例如 `主动`、`条件`、`光环`、`入场`、`遗言`、`反制`、`响应`。一张牌有多个效果时填写多个值。
- `effect_optionality`：填写 `强制` 或 `可选`。一张牌同时包含强制和可选部分时填写两个值。

这些字段服务于读牌、审计和前端展示，不代表运行时可以解析描述自动执行效果。运行时仍以 Go 行为代码为准。

### 2.1 主动效果

主动效果由玩家在允许时机主动使用。主动效果通常只能在自己的出牌阶段使用，除非文本明确写出其他窗口。

常见主动效果：

说明：`主动` 特指在场卡牌除基础机制之外，前端需要额外给玩家按钮/接口主动触发的效果。普通技能、咒术、消耗品道具未写 `主动:` 时，通常是在使用或打出该牌时立即结算文本效果。

```text
主动/强制，消耗：获得1点火焰元素。
主动/强制，回合技1：抽1张牌。
主动/强制，绝技：选择一个敌方单位，造成2点火焰伤害。
主动/可选，回合技1：你可以弃置1张手牌。若如此做，抽2张牌。
```

说明：主动效果通常是“玩家选择是否使用”，但一旦使用，效果本身可以是强制执行。若效果中有“你可以”，应标为主动/可选或在效果内部写出可选部分。

### 2.2 条件效果

条件效果在满足指定条件时触发。新版卡牌文本可使用 `诱发` 表示条件效果。条件效果不能插入当前行动或效果的结算中；它会进入触发队列。

常见条件效果：

```text
条件/强制，入场：抽1张牌。
条件/强制，遗言：对敌方人物牌造成1点暗影伤害。
条件/可选，当你的一个伙伴死亡后：你可以获得1点暗影元素。
条件/强制，当此牌受到伤害后：此牌获得眩晕1。
```

条件效果必须写清楚：触发事件、触发对象、触发后执行什么。

### 2.3 光环效果

光环效果在来源处于有效区域时持续生效。来源离开有效区域、失去效果或被石化后，光环应立即失效或不再被计算。

常见光环效果：

```text
光环/强制：你的火焰法术+1威。
光环/强制：敌方法术-1威。
光环/强制：相邻友方伙伴获得+1生命上限。
```

光环效果通常是强制效果。若存在可选择开启/关闭的持续效果，应写成主动效果产生的持续效果，而不是可选光环。

## 3. 强制与可选

每个效果必须能判断强制或可选，但不要求在效果标签中显式写出。默认规则：未写“可以”的效果视为强制；写了“可以”的触发或执行部分视为可选；`反制` 默认可选触发。

### 3.1 强制效果

强制效果满足条件时必须执行，或主动使用后必须完整尝试执行。

```text
条件/强制，入场：抽1张牌。
条件/强制，祈咒：你受到1点火焰伤害。
光环/强制：你的法术+1威。
```

### 3.2 可选效果

可选效果必须使用“你可以”或明确的选择句式。

```text
条件/可选，当你的一个伙伴死亡后：你可以抽1张牌。
主动/可选，回合技1：你可以弃置1张手牌。若如此做，获得2点奥术元素。
```

可选触发轮到其结算时，由该效果的持有者决定是否执行。不执行视为放弃，不能稍后再触发。

## 4. 标准文本顺序

建议卡牌描述按以下顺序书写：

1. 关键词。
2. 入场限制或额外费用。
3. 光环效果。
4. 条件效果。
5. 主动效果。
6. 反应或反制效果。
7. 额外规则说明。

示例：

```text
速攻。
光环/强制：你的火焰法术+1威。
条件/强制，入场：抽1张牌。
主动/强制，回合技1：选择一个敌方前排单位，造成1点火焰伤害。
```

## 5. 常用标签

推荐使用以下能力标签。

- `入场：` 进入战场后触发。
- `遗言：` 离开战场并进入弃牌堆后触发。
- `游戏开始时：` 人物入场效果结算后、起始抽牌前触发。
- `祈咒：` 持有者回合抽牌后触发。祈咒只定义触发时机；是否强制或可选仍按通用规则由文本决定。
- `回合技X：` 每个轮次可使用 X 次的主动效果。
- `绝技：` 从进入战场到离开战场期间最多使用一次的主动效果。
- `消耗：` 将来源从竖置变为横置作为费用。
- `反制：` 已盖放后，在文本指定事件发生时揭示并使用。
- `反应：` 在指定响应窗口中使用。
- `光环：` 来源在有效区域时持续生效。
- `额外费用：` 除基础费用外必须支付的费用。
- `限制：` 定义打出、使用、选择或结算限制。

## 6. 对象表述

对象必须写清楚所属关系、区域和范围。

推荐用语：

- `你控制的一个伙伴`
- `敌方一个单位`
- `任意一个人物牌`
- `双方所有伙伴`
- `你弃牌堆中的一张技能牌`
- `你手牌中一张已揭示的牌`
- `一个敌方前排单位`
- `一个法力范围内的单位`

避免用语：

- `一个角色`，除非规则定义角色。
- `目标卡牌`，除非任何区域的卡牌都合法。
- `对方卡`，应明确是对手控制、拥有、手牌、场上或弃牌堆。
- `生物`，新文本优先写作伙伴。
- `英雄`，新文本优先写作人物牌。

## 7. 数量表述

数量必须明确是恰好、至多、至少还是任意数量。

推荐句式：

- `选择恰好一个……`
- `选择至多两个……`
- `选择至少一个……`
- `选择任意数量……`
- `每有一个……，……`

## 8. 时机表述

时机必须能对应到规则窗口。

推荐句式：

- `在游戏开始时，……`
- `在你的回合开始时，……`
- `在你的出牌阶段，……`
- `当你施放一个法术后，……`
- `当一个敌方法术以此为目标时，……`
- `当此法术命中时，……`
- `当此法术命中后，……`
- `在伤害结算前，……`
- `在伤害结算后，……`
- `直到回合结束，……`
- `直到你的下个回合结束，……`

`命中时` 在法术伤害前结算；`命中后` 在法术伤害后结算。

## 9. 费用表述

费用必须和效果分开，避免混淆。

推荐句式：

```text
主动/强制，消耗：获得1点火焰元素。
主动/强制，回合技1，支付1点水纹元素：选择一个敌方单位，使其横置。
额外费用：吞噬负载合计至少为3点大气元素的其他友方伙伴。
```

重要区分：

- `消耗` 是横置来源作为费用。
- `透支` 是防御或反制窗口中的特殊支付方式。
- 支付失败时，行动不能声明或效果不发生。
- 奥术支付存在多种合法方案时，玩家必须确认具体支付方式。

## 10. 目标与选择

需要区分“目标”和“选择”。

推荐约定：

- 若对象在行动声明时确定，并会受目标合法性影响，写作 `以……为目标`。
- 若对象在结算过程中决定，写作 `选择……`。
- 随机对象写作 `随机……`。
- 范围法术写清楚 `目标区域` 和 `作用区域`。

示例：

```text
以一个法力范围内的敌方单位为目标。命中后，对其造成2点火焰伤害。
选择至多两个你弃牌堆中的伙伴，将它们移回手牌。
范围：溅射。以一个法力范围内且有单位的区域为目标。
```

## 11. 状态与关键词

关键词应在术语表中定义，卡牌文本只引用关键词名称。

推荐：

```text
速攻。
穿透。
冷却1。
精通2。
范围：方阵。
```

避免：

```text
这张卡可以立刻行动。
攻击时可以打后排。
这名玩家现在精通火。
```

## 12. 持续时间

持续效果必须说明结束点。

推荐用语：

- `直到回合结束`
- `直到你的下个回合开始`
- `直到你的下个回合结束`
- `直到该对象离场`
- `本次伤害结算中`
- `本次法术结算中`

## 13. 结算失败

默认规则：

- 费用未支付：行动或能力不发生。
- 费用支付后，目标变为非法：不退还费用。
- 所有目标非法：效果失效。
- 部分目标非法：只影响仍合法的目标。
- 无可选对象：需要选择对象的效果不发生。
- 强制效果无法完整执行：尽可能执行可执行部分，除非文本要求全部执行。

若某张卡不使用默认规则，必须在文本中写明。

## 14. 生成、绑定与临时对象

生成、绑定或临时对象应写清楚去向和持续时间。

推荐句式：

- `生成一张……并加入你的手牌。`
- `生成一张……并置入你的技能区。`
- `将……作为绑定技能附着到此牌。该绑定技能不占用技能槽，宿主离场时一并消失。`
- `生成一个临时伙伴并置入你的单位区。它在你的回合结束时消失。`

## 15. 反制与反应文本

反制和反应必须写清楚窗口。

反制示例：

```text
反制/可选，当对手召唤一个伙伴后：你可以揭示此牌并支付其使用费用。若如此做，横置该伙伴。
```

反应示例：

```text
反应/可选，当敌方法术命中时：你可以支付此牌的使用费用并横置此牌。若如此做，将该法术造成的伤害改为回复等量生命。
```

反制类道具盖放后占用装备区容量，可以被替换。

## 16. 卡牌审计字段

重写卡牌时，建议每张卡记录以下字段：

```text
卡号
名称
类型
当前描述
新规则文本
效果分类：主动 / 条件 / 光环 / 多段
触发性质：强制 / 可选 / 混合
触发时机
费用或额外费用
目标或选择
持续时间
默认失败规则是否适用
需要的代码行为接口
待确认问题
```

## 17. 禁用写法清单

以下写法应重写：

- `随机触发相关效果`
- `获得对应属性`
- `造成一些伤害`
- `可以进行一次操作`
- `根据情况处理`
- `如果有的话`
- `等等`
- `命中` 用于直接攻击
- `英雄` 作为新文本主术语
- `生物` 作为新文本主术语
- 任何需要读取描述文本才能推断机制的写法

## 18. 模板

### 18.1 伙伴模板

```text
关键词。
光环/强制：……
条件/强制，入场：……
条件/可选，当……时：你可以……
主动/强制，回合技1：……
主动/强制，绝技：……
```

### 18.2 法术模板

```text
关键词。范围：……
条件/强制，命中时：……
条件/强制，命中后：……
```

### 18.3 防御法术模板

```text
防御法术。冷却1。
条件/强制，防御成功时：……
```

### 18.4 咒术模板

```text
主动/强制：选择一个法力范围内的单位，……
```

### 18.5 装备模板

```text
光环/强制：……
主动/强制，消耗：获得……
主动/强制，装备攻击：……
```

### 18.6 消耗品模板

```text
主动/强制：……然后将此牌置入弃牌堆。
```

### 18.7 反制类道具模板

```text
反制/可选，当……后：你可以揭示此牌并支付……。若如此做，……然后将此牌置入弃牌堆。
```
