## 交互结果

- 固定右上卡牌检视区：卡图、费用、状态、前排和类别标签集中显示；己方人物可从点击菜单放大。可见卡图悬停可检视，点击/键盘也能访问详情。
- 卡牌菜单在点击位置右上方打开，按实际尺寸限制在视口内；支持 Enter、方向键、Home/End、Tab、Escape。目标选择优先于菜单，不截获选目标。移除工作区内重复的单位操作面板。
- 简单明确指令（消耗、起手选择、结束回合、规则选择确认、不防御、普通能力、学习）直接提交；绝技、投降等保留复核。多参数行为保留编辑，付款按钮“支付并提交”就是最终提交，无第二次重复确认。纯看牌不发送动作。
- 防御工作区占中间整列，三组并列显示透支、防御/响应、强化。各组内部滚动，取消巨大候选卡图；固定付款、费用/威力和提交区。支持增减付款、重置选择、无效付款禁用，以及只发送一次的最终确认。
- 所有提交仍经过唯一 commitDraft 门禁、在途锁和版本检查。错误保留/同步策略、状态先于回执、连续同类型选择、断线不重发沿用已验证协议。
- 己方盖牌在战场显示牌背且可查看自己授权身份；对手只得到本地通用 SVG 牌背。隐藏牌不会进入菜单或详情，也不产生带隐藏身份的卡图 URL。
- 上下对阵、右下扇形手牌及左下生命覆盖保留。技能/装备/战场采用不同纹理与边框；非交互标签移入检视，横置和前排仍保留边框提示。
