## 验证

2026-10-16 云端 CLI/无头 Chromium 验证通过：

- Go 1.26.1：`go test -count=1 ./...`、`go vet ./...`。
- Node：成本与决策提交状态机测试；`git diff --check`。
- 六组前端脚本：`frontend_card_visibility.py`、`frontend_match.py`、`frontend_reactions.py`、`frontend_quality.py`、`frontend_primitives.py`、`frontend_failed_action.py`。
- 检查完整卡面自然比例、兄弟控件不相交、卡容器不裁切、主布局不横向溢出；滚到战场和候选列表两端后，桌面手牌与确认栏仍在视口内且未被遮挡。实际最终提交也验证按钮可见。

这是本地执行证据，不代表 GitHub CI。此次仅修改前端布局、模板及检查；未修改服务端，本轮没有重跑 race。先前服务端 race 结果见历史材料。

## 边界与材料范围

1024视口中的战场下排、技能/装备需要区域内滚动，密集手牌需横向滚动；它们不会把手牌或确认栏推离桌面视口。手机不承诺手牌与决策同时显示。缩略图印刷小字需通过详情阅读，未做真机或完整无障碍审计。

部分技能池费用图标在云环境显示资源加载失败占位，本次未修复该资源请求；卡图本身已检查成功加载。图片未经修饰以隐藏问题。

图中只有测试玩家名、随机测试房间和游戏卡牌。未包含用户提供的附件、凭据、私人信息、原始日志或上传诊断。
